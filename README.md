# Credit Card Fraud Detection

A machine learning project using **XGBoost** to detect potentially fraudulent credit card transactions, evaluate model performance, and visualise predictions through an interactive Streamlit dashboard.

## Overview

Credit card fraud detection is a binary classification problem in which fraudulent transactions must be distinguished from legitimate ones. This project explores how machine learning can identify suspicious transactions in a highly imbalanced dataset.

## Features

- **XGBoost classifier** for fraud detection.
- **Imbalanced data handling** using `scale_pos_weight`.
- **Model evaluation** using precision, recall, F1-score, a confusion matrix and average precision.
- **Interactive dashboard** built with Streamlit and Plotly.
- **Fraud risk scoring** to identify potentially suspicious transactions.
- **Data visualisation** for exploring transaction patterns.

## Dataset

This project uses the **Credit Card Fraud Detection dataset** available on Kaggle.

**Source:** [Credit Card Fraud Detection — Kaggle](https://www.kaggle.com/datasets/mlg-ulb/creditcardfraud)

The dataset contains 284,807 European credit card transactions from September 2013, including 492 fraudulent transactions.

### Dataset Features

- `Class`: Target variable (`0` = legitimate, `1` = fraudulent).
- `Time`: Seconds elapsed since the first transaction.
- `Amount`: Transaction amount.
- `V1`–`V28`: Anonymised features transformed using Principal Component Analysis (PCA).

### Setup

Download `creditcard.csv` from Kaggle and place it inside the project's `data/` directory. The `dashboard_sample.csv` file is generated by the notebook.

Check the dataset's licence and usage conditions before redistributing the original CSV.

## Model Training

The project uses an XGBoost classifier trained on an 80/20 stratified train-test split.

### Model Configuration

| Parameter | Value |
|---|---:|
| Algorithm | XGBoost Classifier |
| Number of estimators | 200 |
| Maximum depth | 5 |
| Learning rate | 0.1 |
| Random state | 42 |
| Class weighting | `scale_pos_weight` |

The trained model is saved as `models/xgboost_fraud_model.json`.

## Model Evaluation

The model was evaluated on the held-out test set.

| Metric | Result |
|---|---:|
| Accuracy | 99.94% |
| Fraud precision | 84.0% |
| Fraud recall | 82.7% |
| Fraud F1-score | 0.84 |
| Average precision | 0.8655 |

### Confusion Matrix

| | Predicted legitimate | Predicted fraud |
|---|---:|---:|
| Actual legitimate | 56,849 | 15 |
| Actual fraud | 17 | 81 |

The model correctly identified 81 fraudulent transactions, missed 17 fraudulent transactions and incorrectly flagged 15 legitimate transactions.

Accuracy alone is not sufficient for evaluating fraud detection because fraudulent transactions represent a very small proportion of the dataset. Precision and recall provide a more informative assessment of performance on the minority class.

**Evaluation note:** The current workflow also uses the test set as XGBoost's evaluation set during training. A separate validation set would provide a more rigorous evaluation methodology.

## Interactive Dashboard

The Streamlit dashboard provides a visual interface for exploring model predictions.

### Features

- Total transactions scanned.
- Number of transactions flagged as potential threats.
- Value of flagged transactions.
- Transaction scatter plot showing amount, time and predicted risk.
- Detailed table of flagged transactions and their risk scores.

Transactions with a predicted fraud probability above 50% are flagged by the dashboard.

Dashboard predictions are not confirmed fraud, and the value of flagged transactions does not represent verified financial losses prevented.

## Installation and Usage

1. Clone the repository and enter the project folder:

   ```bash
   git clone https://github.com/YOUR-USERNAME/credit-card-fraud-detection.git
   cd credit-card-fraud-detection
   ```

2. Install the dependencies:

   ```bash
   pip install -r requirements.txt
   ```

3. Download `creditcard.csv` from [Kaggle](https://www.kaggle.com/datasets/mlg-ulb/creditcardfraud) and place it in `data/`.

4. Run `training-and-eda.ipynb` to train the model and generate the dashboard sample.

5. Launch the dashboard from the project root:

   ```bash
   python -m streamlit run app/dashboard.py
   ```
